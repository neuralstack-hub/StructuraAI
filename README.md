# StructuraAI

AI-Powered Structural Health Monitoring and Predictive Maintenance Platform.

## Overview

StructuraAI is a software-based prototype for structural inspection assistance using crack image analysis, vibration signal analysis, and explainable evidence fusion.

## Technology Stack

- Python
- FastAPI
- React
- PostgreSQL
- Docker
- GitHub Actions

## Current Status

- [x] Initial FastAPI backend
- [x] Health endpoint

- [ ] Database integration
- [ ] Docker

## Safety Notice

This prototype is an inspection-support tool, not a certified structural safety assessment.
